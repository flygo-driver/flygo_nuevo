Marcas de tarjetas aceptadas

Los pagos con tarjeta en RAI DRIVER son procesados de forma segura por AZUL (Servicios Digitales Popular). Según la documentación oficial de AZUL E-Commerce, aceptamos:

  • Visa y Mastercard (crédito y débito) — requeridas
  • American Express, Discover y otras marcas habilitadas por AZUL

Autenticación 3D Secure

RAI DRIVER utiliza el servicio de autenticación del tarjetahabiente de AZUL (3D Secure). Cuando aplique, el banco emisor solicitará verificación adicional mediante Visa Secure o Mastercard ID Check:

El cobro con tarjeta se realiza en la Página de Pago AZUL (entorno seguro con autenticación 3D Secure). RAI DRIVER no captura ni almacena números de tarjeta, CVV ni fecha de vencimiento en la aplicación ni en sus servidores.

Recibo de pago (pesos dominicanos — DOP)

Política de seguridad en transmisión de datos de tarjetas

RAI DRIVER cumple las mejores prácticas de seguridad para el procesamiento de pagos con tarjeta, delegando la captura y transmisión de datos sensibles a AZUL:

  • Los datos de tarjeta se ingresan únicamente en la Página de Pago AZUL (PCI DSS).
  • Toda comunicación utiliza HTTPS / TLS 1.2 o superior.
  • Autenticación del tarjetahabiente mediante 3D Secure (Visa Secure / MasterCard ID Check).
  • RAI no almacena PAN, CVV, PIN ni banda magnética en servidores propios.
  • Confirmación de pago mediante webhook firmado desde AZUL hacia nuestro backend.
