Política de seguridad para la transmisión de datos de tarjetas

Última actualización: 28 de julio de 2026 · Versión 1.0

Responsable: OPEN ASK SERVICE, S.R.L. (RAI DRIVER)
Dirección permanente: Calle 23 Este No. 39, Ensanche Luperón, Santo Domingo, Distrito Nacional, República Dominicana
Procesador de pagos: AZUL — Servicios Digitales Popular, S.A.

1. Alcance

Esta política aplica a todos los pagos con tarjeta de crédito o débito realizados por usuarios de la aplicación móvil y servicios web de RAI DRIVER, operados por OPEN ASK SERVICE, S.R.L., a través de la pasarela AZUL E-Commerce.

2. Principio de no almacenamiento de datos sensibles

OPEN ASK SERVICE, S.R.L. no solicita, no captura, no transmite ni almacena en sus servidores o bases de datos los siguientes datos de tarjeta:

  • Número de tarjeta completo (PAN)
  • Código de verificación (CVV/CVC)
  • Fecha de vencimiento completa
  • PIN o datos de banda magnética

La captura de datos de tarjeta se realiza exclusivamente en la Página de Pago AZUL, entorno certificado PCI DSS operado por Servicios Digitales Popular.

3. Método de integración

RAI DRIVER utiliza el modelo de Página de Pago alojada (Hosted Payment Page) de AZUL:

  1. El usuario inicia el pago desde la aplicación RAI DRIVER.
  2. El servidor de RAI (Firebase Cloud Functions) crea una sesión de pago y obtiene la URL segura de AZUL.
  3. El usuario es redirigido a la Página de Pago AZUL mediante conexión HTTPS.
  4. El usuario ingresa los datos de su tarjeta directamente en el formulario de AZUL.
  5. AZUL procesa la transacción, aplica 3D Secure si corresponde, y notifica el resultado a RAI mediante webhook seguro.
  6. RAI registra únicamente datos no sensibles: estado del pago, referencia de orden, código de autorización y últimos cuatro dígitos (si AZUL los provee).

4. Cifrado y transmisión segura

  • TLS 1.2 o superior: toda comunicación entre la aplicación, los servidores de RAI (Google Firebase) y la plataforma AZUL se realiza mediante HTTPS cifrado.
  • Certificados digitales: la Página de Pago AZUL opera con certificado digital válido emitido para el dominio de AZUL.
  • Sin transmisión en texto plano: en ningún punto del flujo RAI se transmiten datos de tarjeta en texto plano.

5. Autenticación del tarjetahabiente (3D Secure)

RAI DRIVER adopta el servicio de autenticación del tarjetahabiente ofrecido por AZUL, compatible con Visa Secure y MasterCard ID Check. Cuando el emisor de la tarjeta lo requiera, el usuario será dirigido al portal de su banco para verificar su identidad antes de completar el pago.

6. Cumplimiento PCI DSS

Al utilizar la Página de Pago AZUL, OPEN ASK SERVICE, S.R.L. delega el cumplimiento PCI DSS en el ámbito de captura y procesamiento de datos de tarjeta a AZUL / Servicios Digitales Popular, quien actúa como proveedor de servicios de pago certificado.

Los servidores de RAI almacenan únicamente tokens opacos, referencias de transacción y metadatos de conciliación provistos por AZUL.

7. Control de acceso

  • Solo el usuario autenticado titular del viaje puede iniciar un pago con tarjeta.
  • Las reglas de seguridad de Firebase Firestore impiden que clientes o terceros modifiquen campos de pago AZUL.
  • Los webhooks de AZUL se validan mediante firma o mecanismo de autenticación acordado con AZUL.
  • El acceso administrativo a datos de pago está restringido a personal autorizado de OPEN ASK SERVICE, S.R.L.

8. Monitoreo y registro

RAI registra eventos de pago (creación de sesión, confirmación, rechazo) con fines de auditoría, conciliación y soporte al cliente. Estos registros no contienen datos sensibles de tarjeta.

9. Notificación de incidentes

En caso de incidente de seguridad relacionado con pagos con tarjeta, OPEN ASK SERVICE, S.R.L. notificará a AZUL y a las autoridades competentes conforme a la normativa aplicable en República Dominicana.
