1. Resumen ejecutivo

RAI Driver Corporativo lleva o regresa a su personal con ruta fija, chofer conocido, precio acordado y factura consolidada — sin flota propia y sin app para cada empleado.

  • Rutas con origen, pasajeros y destinos GPS (una vez).
  • Chofer fijo asignado por RAI (no taxi suelto).
  • Publicación automática cada día operativo.
  • Un código del período; al pagar se genera uno nuevo.
  • Factura semanal, quincenal o mensual.

Resultado: menos WhatsApp a las 6:45 AM, personal a tiempo, números claros para gerencia.

3. Cómo funciona

  1. RAI activa contrato, tarifa y asigna chofer.
  2. Encargado arma la ruta (origen → destinos GPS → horario) y el ciclo de pago.
  3. ~90 min antes: viaje automático + push al chofer; ~40 min recordatorio.
  4. Empleados dictan el código del período → destinos uno a uno.
  5. Al corte: liquidación → bauche a RAI → código nuevo.

Después de configurar, el encargado no arma el viaje cada mañana. Solo excepciones y el pago.

ACTIVACIÓN → contrato + tarifa CONFIGURACIÓN → ciclo + ruta GPS ADMIN RAI → asigna chofer CADA DÍA → publica · código · destinos · suma a cuenta PAGO → liquidación · bauche · código nuevo
